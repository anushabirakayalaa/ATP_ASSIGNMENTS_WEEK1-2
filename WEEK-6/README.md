# Week 6 - HTML, CSS, Flexbox, Grid, Responsive Design, and Tailwind

This week focuses on frontend layout practice using plain HTML/CSS and Tailwind CSS.

## Topics Covered

- HTML page structure and linking CSS files.
- Flexbox layout with rows, wrapping, navigation bars, cards, and responsive sections.
- CSS Grid layout with multi-column page sections and custom grid positioning.
- Media queries for mobile-friendly layouts.
- Tailwind CSS setup using the CLI and browser CDN.
- Styling cards, landing sections, travel pages, and grid-based product-style layouts.

## Main Folders

- `ASSIGNMENTS/` - HTML/CSS assignment pages including simple card layouts, responsive pages, city/travel layouts, and tourism sections.
- `FLEX-GRID/` - larger layout projects combining Flexbox and Grid with images and multiple content blocks.
- `Others/FLEX/` - Flexbox practice including colors, responsive layouts, navigation, and card-based sections.
- `Others/GRID/` - CSS Grid practice with fixed and responsive grid placement.
- `TAILWIND-DEMO-1/` - Tailwind CSS CLI setup with `style.css`, generated `output.css`, and a sample HTML page.
- `TAILWIND_CSS/` - simple Tailwind CDN usage in HTML.

## Outcome

The code demonstrates practical layout skills using Flexbox, CSS Grid, media queries, and Tailwind utility classes.
