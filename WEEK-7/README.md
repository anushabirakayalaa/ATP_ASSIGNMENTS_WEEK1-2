# Week 7 - React with Vite

This week introduces React application development using Vite, JSX, components, props, state, effects, forms, and lists.

## Topics Covered

- React + Vite project setup.
- JSX and component-based UI.
- Props for passing data from parent to child components.
- Rendering lists with `.map()`.
- Conditional rendering.
- State management with `useState()`.
- Side effects and API fetching with `useEffect()`.
- Form handling with `react-hook-form`.
- Tailwind CSS utility styling.

## Projects

- `react-demo-2/` - product showcase app.
  - `Products` stores an array of 10 tech products.
  - `Product` receives each product through props and displays image, name, brand, description, and price.

- `HANDS-ON/` - country explorer app.
  - Fetches country data from the REST Countries API.
  - Includes a search input with auto-focus and debounced filtering.
  - Displays country cards with flag, capital, population, and region.

- `TASK-MANAGER/` - task manager app.
  - Adds tasks using a form.
  - Displays task list and total task count.
  - Includes extra practice components for state, forms, registration, and props.

- `Others/` - additional JavaScript and HTML/CSS practice.

## Outcome

The code demonstrates how to build small React apps by composing components, passing props, managing state, handling forms, and fetching external data.
