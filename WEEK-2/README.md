# Week 2 - JavaScript Modules, Dates, Copies, and Classes

This week focuses on organizing JavaScript code into modules and solving larger tasks using reusable functions.

## Topics Covered

- ES module imports and exports.
- Date creation, formatting, comparison, validation, and age calculation.
- Shallow copy and deep copy using object spread and `structuredClone()`.
- Class-based programming with a `Book` class for a library management system.
- Functional data processing with immutable updates.

## Projects and Tasks

- `E-COMMERCE_SHOPPING_CART_SYSTEM/` - modular shopping cart system with product catalog, cart operations, coupon validation, discount calculation, payment processing, stock updates, and order summary.
- `TODO/` - task manager module with title, priority, and due-date validation before adding or completing tasks.
- `master-project-collection/` - collection of modules for user processing, course processing, cart/course merging, and role-permission handling.
- `date.js` - date extraction, deadline checking, invalid date checking, and age calculation.
- `deep-shallow-copy.js` - comparison of shallow copy and deep copy behavior.
- `librarybookman.js` - class-based library book management with borrow, return, info, availability, and long-book checks.

## Outcome

The code shows how to split logic across files, reuse functions, manage structured data, and apply object-oriented programming in JavaScript.
