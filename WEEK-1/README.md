# Week 1 - JavaScript Fundamentals

This week covers the basic building blocks of JavaScript through small practice tasks and assignments.

## Topics Covered

- Arrays and array methods such as `filter()`, `map()`, `reduce()`, `find()`, and `findIndex()`.
- Object creation, property updates, deleting properties, `Object.keys()`, and `Object.freeze()`.
- Control statements using `if`, `else if`, and ternary operators.
- Operators for bill calculation, login checks, enrollment checks, and course pricing.
- Simple data processing tasks for carts, students, employees, movies, transactions, temperatures, courses, and marks.

## Main Folders

- `arrays/` - array method assignments using real-world examples like shopping carts, marks, payroll, movies, and bank transactions.
- `array-operations-simple/` - beginner array practice with temperatures, course names, and marks.
- `objects/` - object-based tasks for user profiles, exam results, and application settings.
- `control-statements/` - decision-making exercises for login status, course tags, and enrollment eligibility.
- `operators/` - billing calculation using arithmetic and assignment operators.
- `others/` - extra JavaScript practice files.

## Outcome

By the end of this week, the code demonstrates how to work with basic JavaScript data types, arrays, objects, conditions, and operators.
